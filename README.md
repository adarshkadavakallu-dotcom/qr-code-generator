# QR Code Generator

A simple and responsive QR Code Generator built with HTML, CSS, and JavaScript.

## Features

- Generate QR codes from text or URLs
- Enter key support
- Multiple QR code sizes
- Custom QR color
- Custom background color
- Download QR code as PNG
- Copy QR code to clipboard
- Clear and reset
- Input validation
- Responsive design for mobile and desktop
- Error handling

## Technologies Used

- HTML5
- CSS3
- JavaScript
- QRCode.js
- Clipboard API

## How It Works

1. User enters text or a URL.
2. JavaScript reads the input.
3. QRCode.js generates the QR code.
4. The QR code is displayed on the webpage.
5. The user can download or copy the generated QR code.
